// 02 Engineering side projects

Five systems I built and still run. They share one architecture on purpose: pure, injectable domain logic with no UI imports; a single layer allowed to touch the network; every network call cached and degrading to stale rather than crashing; and a test suite that runs with the network unplugged.

These repositories are private and stay private — they hold a real household's financial records. What follows describes the engineering only. Nothing here is financial advice, and none of it trades real money.

Quantum-inspired portfolio selection

optimization

Picking the best K stocks out of N is a combinatorial problem — thirty candidates and ten slots is about thirty million subsets, so you cannot simply enumerate them. Posing it as a QUBO turns selection into minimising one quadratic form over binary variables, which a simulated annealer can attack directly. The annealer is 170 lines of numpy: a geometric inverse-temperature schedule, an O(N) incremental energy update per bit flip, and a seeded master/sub RNG so two runs are bit-identical.

It sits inside a nine-level learn-to-trade curriculum, where seventeen interactive labs let a reader break the thing themselves — including one whose entire purpose is to show what happens when the cardinality penalty is scaled wrong. Small instances are checked against brute-force enumeration, so the annealer has to prove it finds the true minimum rather than merely a good one.

Multi-market strategy tournament

research rig

Seventeen strategies race across four markets: rule-based baselines, portfolio constructions on a shared shrunk-covariance scaffold, walk-forward-retrained scikit-learn models, an online multiplicative-weights ensemble, and an LLM allocator. A walk-forward backtest tournament ranks them offline; a live paper A/B runs them all forward in parallel; exactly one champion is promoted by hand.

The most useful thing it produced was a correctness review that invalidated every number it had reported until then — warm-up silently eaten out of the requested window, a normalisation helper quietly re-levering every book to fully invested, and metrics that ranked a strategy which never lost money as the worst in the field. That review roughly doubled the test count.

Multi-currency portfolio dashboard

data modelling

Twelve asset types across several markets, valued in a currency the reader picks at runtime, over a history that must stay comparable across years. The hard part is not the arithmetic — it is keeping two currencies apart: an immutable one that every stored snapshot is denominated in, and a display one that changes whenever someone touches a dropdown. Confuse them and the net-worth chart grows a step change through its middle.

It is also where I learned that a missing price is not a zero price. A failed quote returning zero, paired with a real cost basis, books a fabricated total loss — and then tops the chart of biggest movers, which is exactly where you are least likely to question it.

Statement parser and spend tracker

document parsing

Bank and card statements arrive as PDFs, each issuer laying out its tables differently, several of them badly. This reads them, classifies every line, and presents a month in a bilingual dashboard. Routing moved from filenames to content early on — a folder of original download names now works untouched, because the parser identifies an issuer from the text of the first page.

Two decisions carried it. Bank rows are read as a running-balance delta rather than by parsing amounts, so a sign is never guessed. And every parsed total is reconciled against the total the statement itself prints — a failed reconciliation is reported as a failure, because silently correcting it would defeat the point of having an oracle.

privacy-guard

developer tooling

A scanner that looks for personal data in a repository before it can leave the machine, wired into pre-commit and pre-push hooks on every repo here, into a hook that intercepts an AI agent's shell commands, and into a weekly audit that also verifies the hooks are still installed. Stdlib only, so it runs on whatever Python is on the box with no environment to set up.

Its central constraint is self-referential and pleasing: a scanner must not embed the secrets it hunts for, or it becomes another copy of the leak. So the code carries only generic patterns and checksums, and the specific values live in an uncommitted local file. Findings are redacted before printing — including every other number on the same line, since a line listing three balances would otherwise mask one and publish two.

// 03 The shape they share

Eight repositories converged on one architecture, largely because each rule in it replaced a bug.

The habit underneath is narrower than the diagram: write the check that would have caught it. A colour palette that has to pass a computed colour-blindness check. A test that asserts an optimizer never sees a future bar. A build that fails if a contrast ratio drops below 4.5:1 — including on the page you are reading. None of these are clever. They are just the difference between believing a system works and knowing.
